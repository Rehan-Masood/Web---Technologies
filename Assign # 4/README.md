# ⚡ Installation Guide

## 1. Clone Project

```bash
git clone https://https://github.com/Rehan-Masood/Web---Technologies/tree/main/Assign%20%23%204
```

---

## 2. Open Project

```bash
cd taskflow-pro
```

---

## 3. Install Dependencies

```bash
composer install
npm install
```

---

## 4. Configure Environment

Copy `.env.example`

```bash
cp .env.example .env
```

Update database settings inside `.env`

```env
DB_DATABASE=todo_premium
DB_USERNAME=root
DB_PASSWORD=
```

---

## 5. Generate Application Key

```bash
php artisan key:generate
```

---

## 6. Run Database Migration

```bash
php artisan migrate
```

---

## 7. Start Development Server

```bash
npm run dev
php artisan serve
```
