# User Management System Using Laravel

## Project Overview

This is a Laravel-based User Management System developed as a web application assignment. The system allows an administrator to register users, view user records, update user information, delete users, search users by email, and upload profile pictures.

The project uses Laravel, PHP, MySQL, XAMPP, phpMyAdmin, HTML, CSS, and Blade templates. The interface is designed with a modern dark premium dashboard theme.

## Features

- User registration form
- Store user data in MySQL database
- Upload profile picture to `public/uploads`
- Display all users in a table
- Edit user information
- Delete user with confirmation popup
- Search users by email
- Dashboard cards for total users and new registrations
- Recent activity section
- System status panel
- Premium dark responsive interface
